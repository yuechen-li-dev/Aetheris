# Producer / consumer matrix

| Producer | Exposed evidence | Consumers proved in M1 |
| --- | --- | --- |
| Direct Firmament profile | exact validated profile | Profile, Compose, Selection admission, admitted Modify |
| Concept Path | profile binding plus typed guide/endpoint members | Profile, Compose; ordinary selection after materialization |
| Template + Table/Record/with | same output value plus specialization/input provenance | same as native output |
| InlineStep/Recognize | exact imported face/region and STEP association | structured member path, Selection, FEA, admitted face Modify |
| Forge SecretCoupon | exact body, `TopFace`, `LoadRegion` | structured member path, Selection, FEA, admitted face/body Modify |

There are no origin-named consumer implementations. Recognition import
association checks and Forge output checks remain producer validation, not
consumer adapters.
