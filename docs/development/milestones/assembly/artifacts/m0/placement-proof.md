# Placement proof

The Housing anchor is identity. The Shaft/Bearing and Shoulder/Seat axis directions are solved analytically. The axis-plus-plane Interface removes translation; axial symmetry is explicitly admitted as `rotation:about-axis`, so the Shaft placement is `Resolved`, not silently arbitrary. Axis-only tests without admitted freedoms report translation along and rotation about the axis. Conflicting axis Mates produce `assembly-placement-overconstrained` with the involved Mate IDs and transform residual threshold.
