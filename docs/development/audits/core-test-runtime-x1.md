# Core test runtime audit

The 2026-09-23 serial Core run took 8m47s for 1,099 tests. A TRX profile is retained at ignored `Aetheris.Kernel.Core.Tests/TestResults/core-profile.trx`. The largest single test was the aggregate NIST audit (213s). The per-file NIST snapshot class accumulated 493 test-seconds while executing each file twice, and the separate export/reimport sweep accumulated 321 test-seconds across 17 files. Display and orientation corpus classes each prepared the same 14 meshes, accumulating 193 and 169 test-seconds respectively. These are test durations summed across xUnit workers, not additive wall time.

The Core suite now keeps one NIST per-file snapshot comparison and a manifest gate, removes second `RunOne` executions that only compared identical report fields, and reimports a three-file CTC/FTC/STC sample. The manifest audit still imports and exports every NIST file; the sample remains responsible for exporter-to-importer topology. The display corpus still checks every admitted face, and outward winding still covers the same 16 files; the 14 shared files use one prepared mesh for both assertions.

This change does not alter the production tessellator or its display options. The profile identified repeated whole-model import/export and duplicate test mesh preparation as the immediate cost. The ordinary iteration command remains `scripts/Test-KernelIteration.ps1`; full corpus qualification remains available in the serial full suite.

After the edits, the serial Core run passed 1,071 tests in 3m51s, down from 1,099 tests in 8m47s (56% less wall time). The final ignored TRX is `Aetheris.Kernel.Core.Tests/TestResults/core-final-profile.trx`. Summed xUnit test durations fell from 2,898s to 1,657s; these sums overlap because tests execute concurrently. Remaining longer cases include CTC-02 periodic orientation/export detail and a few complex display regressions, each with an assertion distinct from the NIST snapshot. Snapshot refresh remains explicit through `AETHERIS_UPDATE_STEP242_SNAPSHOT=1`.
