# Graph authoring inputs

These sources exercise the compiler-owned structural edit API. `plate`,
`placement`, and `assembly-starter` are complete accepted documents.
`profile.firmament` is intentionally an unfinished authoring input: its Profile
becomes an admitted solid only after `extrudeProfile`. It is not a must-build
corpus specimen. `FirmamentGraphAuthoringTests` qualifies the resulting source,
stable feature identities, retained support faces, placements and leaf geometry.
