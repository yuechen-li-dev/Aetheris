# Educational migration

The through-hole recipe entry documents its known input family, seven-face
output, ring/seam orientation, validation expectations, and the cases that
break the contract. The polygonal recipe documents the contrasting ordered-wall
lesson. The old builder entry points remain named adapters/parity seams rather
than deleted teaching logic.

`docs/development/architecture/kernel/brep-surgery.md` now follows a complete recognized request through
geometry, loops, faces, assembly, validation, STEP, and reimport and includes a
recipe checklist. `docs/development/architecture/kernel/brep-boolean-lessons.md` now covers the API
illusion, intersection-versus-topology, through/blind/stepped holes,
counterbores, polygonal contrast, and the generic-CIR limitation.
