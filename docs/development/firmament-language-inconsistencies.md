# Firmament language inconsistency register

This development-only register records dialect differences exposed while consolidating the Preview 3 documentation and fixture corpora. It does not define current syntax and A5b deliberately changes none of the forms below. The public authority is [`docs/public/firmament`](../public/firmament/overview.md).

Runtime-support labels are: `Canonical`, `AcceptedLegacyAlias`, `DomainSpecificByDesign`, `StaleDocumentationOnly`, `FixtureOnlySpeculation`, `PotentialParserInconsistency`, and `UnknownNeedsAudit`.

## Priority for a later language pass

- **High:** through/extent value families; overlapping Template/Compose/Modify/derivation mechanisms; the exact casing acceptance matrix where route selection may differ.
- **Medium:** V1 migration/support policy; PMI record aliases; EdgeFinish versus low-level operation vocabulary; unit conventions at parser boundaries.
- **Low:** historical TOON spelling and cosmetic identifier differences that remain quarantined under `LegacyV1/` or development history.
- **Intentional:** Model versus Sheet Metal targets and hole declarations; assembly-domain documents; imported identifiers and material designations that preserve external spelling.

No syntax, alias, parser behavior, lowering, or runtime semantics were changed while producing this inventory.
