# AETHERIS-BUNNY-M4 evidence

M4 exposes the reusable experimental `SurfaceReconstruction.Remesh` Fast path and `aetheris reconstruct mesh`. The canonical Bunny succeeds in 2.451 s median engine time (3.149 s median process time), produces 95.427% quads, and preserves 5 intentional boundary loops with no cracks or non-manifold edges.

## Showcase model

[Download `bunny-fast-structured-remesh.obj`](bunny-fast-structured-remesh.obj) (2.12 MB). It contains the full 35,947-vertex result: 33,913 quads and 1,625 explicit transition triangles. Open it in Blender, MeshLab, or another OBJ viewer and enable edge display to inspect the structured layout.

This is approximate reconstructed geometry generated by Aetheris from the Stanford Bunny `bun_zipper.ply`. The source model is credited to the Stanford University Computer Graphics Laboratory. Stanford permits free mirroring and redistribution with acknowledgment; commercial use requires their permission. The dataset terms and original model are available from the [Stanford 3D Scanning Repository](https://graphics.stanford.edu/data/3Dscanrep/). This derived showcase mesh is distributed subject to those dataset terms and is not relicensed under Aetheris's AGPL.

Fast deliberately stops after bounded local matching. It does not run M3's global blossom/coarsening research path, materialize 33k strict Panels, or fit residual maps that do not materially improve the scale-derived tolerance.

Reproduce from the repository root with the command documented in `docs/geometry/experimental-remeshing.md`. Only the canonical showcase OBJ is tracked; error PLY, correspondence, and other per-sample outputs remain under ignored `.tmp/` paths.
