# Aetheris 2.0.0

Aetheris is a code-first CAD kernel with a browser-based viewer. Describe a
parametric part or assembly in **Firmament**, build an exact 3D model, and export
STEP files for other CAD tools or manufacturing. Keep the design in Git, review
changes in a pull request, and generate your engineering artifacts in CI.

**Cadmata**, the included viewer, lets you inspect STEP models, select faces and
edges, measure geometry, and view dimensions and tolerances. It runs locally in
your existing browser. You do not need another browser installation or a cloud
service.

## Download and start

Choose your bundle from the assets below. Each includes the compiler, Cadmata,
examples, documentation and the .NET runtime. No SDK, Node.js or checkout is needed.

| Computer | Download | Start the viewer |
| --- | --- | --- |
| Windows, Intel/AMD 64-bit | `Aetheris-2.0.0-win-x64.zip` | Extract, then double-click `Cadmata.exe` |
| Linux, Intel/AMD 64-bit | `Aetheris-2.0.0-linux-x64.tar.gz` | Extract, open the folder in a terminal, run `./Cadmata` |
| macOS, Apple Silicon (M-series) | `Aetheris-2.0.0-osx-arm64.tar.gz` | Extract, then open `Open Cadmata.command` or run `./Cadmata` in Terminal |

Choose a `.step` or `.stp` file in Cadmata and click **Import STEP 242**.
Drag to orbit, choose a standard view, or use **Measure** to inspect your model.
Try the product gallery to start with an included example.

Keep the launcher terminal open while using Cadmata. Press **Ctrl+C** there to
stop the local service; closing the browser tab alone does not stop it.
Windows also includes an optional `Cadmata.Desktop.exe` window using shared WebView2.

The macOS download is not notarized. If blocked, verify the download and use the
per-app **Open Anyway** control in **System Settings → Privacy & Security**.
See the [bundle guide](https://github.com/yuechen-li-dev/Aetheris/blob/master/docs/public/release-bundle.md)
for platform requirements and launch instructions.

## Build your first part

From the extracted bundle directory:

```sh
./aetheris build fixtures/Canonical/PMI/hole-diameter-and-datum.firmament --output first-part.step
./aetheris view first-part.step
```

On Windows PowerShell, use `.\aetheris.exe` instead of `./aetheris`.
This example makes a plate with a through hole, a datum and a toleranced diameter.
Change the dimensions in its `.firmament` file and rebuild.
[Learn Firmament](https://github.com/yuechen-li-dev/Aetheris/blob/master/docs/public/learn/README.md)
walks through parts, reusable designs and assemblies.

Already have .NET 10? Install just the CLI with
`dotnet tool install --global Aetheris.CLI --version 2.0.0`.
The CLI-only NuGet package does **not** include Cadmata. C# developers can also
use the Aetheris libraries directly from NuGet.

## Feature summary

- **Parametric parts:** primitives, profiles, extrusions, supported revolves and
  sweeps, holes, slots, pockets, fillets and chamfers.
- **Reusable designs:** typed parameters, templates, records and patterns for
  families of parts.
- **Assemblies:** parts and subassemblies connected through named interfaces,
  reference geometry and supported mates.
- **Manufacturing information:** sheet metal and flat patterns; dimensions,
  datums, tolerances and semantic PMI in STEP AP242.
- **STEP inspection and bounded editing:** import existing parts, measure them,
  inspect their topology and PMI, and revise supported recognized through holes.
- **Deliverables:** STEP, meshes including glTF/STL, and PDF/SVG/PPTX drawings
  for supported drawing classes. Export availability depends on the model and
  command; not every output is a Cadmata menu item.
- **Automation:** validation, builds, inspections and bounded structural analyses
  from scripts or CI, with structured diagnostics.

See the [feature guide](https://github.com/yuechen-li-dev/Aetheris/blob/master/docs/public/reference/supported-features.md)
for supported combinations and examples.

## Known issues

- Geometry operations support documented combinations, not arbitrary booleans,
  general edge blending or unrestricted imported-body editing.
- Automatic drawings cover specific part families. Review dimensions, datums,
  tolerances and process capability before sending a drawing to a shop.
- Some imported models are inspectable but cannot be fully edited, measured or
  re-exported. Import reports disclose limitations; original files are unchanged.
- Some valid models have no tessellated volume estimate. That alone does not mean
  their exact STEP geometry is invalid.
- Complex swept or spline-heavy validation can take seconds. Diagnostics after
  expansion sometimes identify the enclosing construct rather than the original token.
- Use a modern browser with hardware acceleration; WebGL fallback is available. Linux targets glibc, not Alpine/musl.
  Intel Macs and Linux arm64 do not have a qualified bundle in this release.
- Cloth and humanoid APIs remain experimental. Structural analysis is bounded
  linear elasticity, not general simulation or certification.

[Detailed limitations](https://github.com/yuechen-li-dev/Aetheris/blob/master/docs/public/reference/known-issues.md)
are documented separately. Aetheris is **AGPL-3.0-only**; dependency notices and
corresponding-source links are included in the bundles.
