- Firmament V2: philosophy, language tour, values/tolerances, Records/Tables/Templates, semantics, datums/dimensions, Profiles/Compose, InlineStep, language reference, feature status.

- Analysis: Continuum, FEA.
- Assemblies: Interfaces/Mates, tolerance stackup.
- Examples: bearing module, Template block pair, plate with hole, imported STEP.
- Tools & reference: CLI, cookbook, LLM/tool authors, architecture, VS Code, diagnostics, compatibility.

Ten Preview 1 paths remain aliases, including Concept Path, static authoring, mechanical feature pages, existing STEP, verification, and support status. Vite emits static HTML for all 43 stable routes.
