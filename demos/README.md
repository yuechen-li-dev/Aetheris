# Demos

Demos are runnable narrative demonstrations of an Aetheris capability. Keep the owning project, authored assets, runner, and explanation together.

The [code-native bracket rehearsal](../docs/public/code-native-bracket.md) generates
a typed parametric L bracket, STEP/GLB/PDF artifacts and PDF-only reconstruction evidence.

Use [`samples/`](../samples/README.md) for external-consumer integration examples. Regression-only Firmament source belongs under [`fixtures/`](../fixtures/README.md). The `.firm` extension is local to `Aetheris.PmiInjectionDemo`'s overlay template/output and is not a general Firmament document type. Per-run demo output belongs under ignored `artifacts/local/demos/`.
