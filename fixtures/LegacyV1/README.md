# Legacy V1 fixture corpus

This subtree preserves executable TOON-style Firmament regression material that is still exercised by tests. It is intentionally separate from canonical Preview 3 authoring while remaining inside the one `fixtures/` kingdom.

`Corpus/valid`, `Corpus/invalid`, and `Corpus/deferred` classify the former flat corpus by its manifest outcome and explicit unsupported status. The manifests are retained under `Corpus/manifests/`. Other folders preserve examples, experiments, reconstruction inputs, and verification sources without changing their language semantics.
