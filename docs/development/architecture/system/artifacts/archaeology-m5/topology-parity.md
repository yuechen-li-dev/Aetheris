Differential coverage retains the old facade as a test oracle. Direct through-hole output matches it for vertices, edges, faces, loops, coedges, curves, surfaces, edge/face bindings, and canonical STEP SHA-256. The canonical result remains seven faces, nine loops, thirty coedges, and one cylindrical support. STEP export/reimport and complete binding validation pass.

Translated semantic input also matches the facade. CIR preserves replay feature identity; StandardLibrary records its known part feature ID. These are history/provenance gains and do not alter STEP topology. Surgery validation runs on every comparison.

The request builder calls bounded composition policy directly. Per migrated execution it removes one root recognition, one tool analytic recognition, the related dispatcher classification, and both temporary primitive constructions where the caller previously built them.

Representative 30-iteration measurements (diagnostic regression test, not a benchmark suite): Firmament 11.229 ms facade vs 1.857 ms direct; CIR 5.071 ms vs 1.833 ms; StandardLibrary 4.977 ms vs 1.908 ms. The direct path is faster in all three samples because it skips operand construction and re-recognition.
