# FORGE-SDK-M1 evidence

Evidence is regenerated by:

```powershell
dotnet run --project tools/Aetheris.Forge.M1Evidence/Aetheris.Forge.M1Evidence.csproj -f net10.0
```

Files:

- `current-forge-audit.md`: pre-change responsibility and coupling audit.
- `api-surface-summary.md`: public M1 surface.
- `capabilities.json`: inspectable registered capability metadata.
- `template-metadata.json`: typed Template signature and generated name.
- `invocation.json`: generated-binding/host invocation evidence.
- `provenance.json`: host-to-artifact provenance trace.
- `brep-validation.json`: topology counts and BRep/STEP validation.
- `cli-analysis.json`: independent `Aetheris.CLI analyze --json` ground-truth inspection.
- `cir-association.json`: ordinary CIR/BRep association result.
- `determinism.json`: repeated artifact and STEP hashes.
- `performance.json`: registration, resolution, Template, extension, and compiler-stage wall times.
- `sample-secret-coupon.step`: validated external-capability AP242 artifact.

The sample capability implementation is confined to `Aetheris.Forge.SampleExtension`; no capability-specific source exists in `Aetheris.Kernel.Core`.
