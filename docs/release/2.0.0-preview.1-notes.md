# Aetheris 2.0.0-preview.1

First public preview of Aetheris, the exact code-first CAD compiler.

## Highlights

- Firmament V2 and deterministic STEP AP242 output.
- Primitives, profiles, Compose, bounded mechanical features, PMI, verification, and bounded existing-STEP workflows.
- Cadmata viewer in the Windows bundle and the Aetheris Firmament VS Code extension.

## Install

Download and extract the Windows bundle for the complete CLI and Cadmata viewer,
or run `dotnet tool install --global Aetheris.CLI --prerelease` for the CLI.

## Important Preview limitations

- Mixed whole-loop Fillet remains Experimental.
- Concept Path-derived Profiles are not accepted by Compose.
- Foreign STEP recognition/replacement is deliberately bounded.
- The known Parasolid chamfer interoperability limitation remains.
- Tessellated B-rep volume is non-authoritative; CIR/FRep expansion is deferred.
