## Remaining blocker and next bounded capability

**Verdict: Meaningful progression.** The correct body is identified, measured, and redrawn as a small editable Firmament model with a real enclosed production STEP. It does **not** yet match the source base within the documented 1 mm threshold because the source underside has a 7 mm offset rounded-rectangle subtraction. The source's rough Boolean makes that subtraction meet the outer side and large opening. This is an ordinary pocket construction, not a need to reproduce the source's complex NURBS control nets. Below `z=7` it splits the remaining plate material into two XY regions, which the top plate reconnects in 3D. The hex nut and hollow cylindrical pole interface visible in the bottom view are separate source bodies 6–8, so they are recorded as local interface context rather than merged into this plate STEP.

An attempted `Compose Body` with the cubic profile is rejected with `Profile arrangements require bounded line or circular-arc source curves.` A seven-arc outline trial admits composition, but a source-sized underside cut is rejected as `arrangement-rejected:disconnected-or-invalid-material:outer-loops=2:context=slab=(0,7)`. A smaller contained pocket compiles but leaves the source-like connection and much of the 7 mm mismatch unresolved. A `Modify Body Pocket` trial after the cubic extrusion emitted the same eight-face STEP, so it did not provide a valid relief either. The minimal capability gap is a profile/pocket materialization route that accepts the existing polynomial flank and a connected 3D solid whose intermediate slab has two material loops. It should preserve one canonical BRep/STEP authority and diagnose unsupported cuts explicitly. Until that is available, adding cosmetic rim fillets or more small details would not converge on base qualification.

Mechanical work suitable for automation includes source object/trim inventory, sampled trimmed-edge envelope, analytic opening measurements, bounded outline fitting, source-to-profile residuals, STEP entity counts, and deterministic reimport checks. The decisions to select object 5, use the opening as datum, treat separate collars as separate parts, choose a three-segment perimeter, and admit a 1 mm redraw threshold remain explicit engineering judgments. An independent fresh agent given this measurement plan and public Firmament docs proposed profile extrusion, circular openings, and later underside validation; it correctly rejected original-history recovery and accepted a small non-rational spline only with measured qualification.
