# Aetheris 2.0.0 known issues and limitations

- Bundles target Windows x64, Linux x64 (glibc) and macOS arm64 (Apple Silicon). The macOS bundle is not Developer ID signed or notarized. Intel Macs, Linux arm64 and Alpine/musl have no qualified bundle. See the [launch guide](../release-bundle.md) for requirements.
- `inlineSTEP` FEA supports the documented single-body imported class and stable imported face identities. Arbitrary imported containment and multi-root assembly-like STEP are rejected explicitly; some OCCT B-spline containment cases remain outside the qualified class.
- The generic tessellated mass verifier can report `Unavailable` for some valid combined analytic Boss/Pocket/hole models when a face cannot be triangulated. STEP reimport, manifold checks, analytic surface inventory, bounds, and route-specific analytic volume remain available; do not interpret an unavailable tessellation estimate as a topology failure.
- Composed profiles admit bounded +Z through counterbore/countersink entries with complete disjoint footprints and positive shaft length. Oriented Compose hole adapters, entry breakouts and chamfer corridors crossing a cavity transition remain explicitly rejected. Sheet Metal Counterbore and Countersink are rejected because those formed-opening semantics are not implemented.
- Composed-body fillets require a cavity-preserving adapter over the existing body. The standalone Profile fillet planner constructs a new extrusion; the compiler rejects applying it to Compose rather than losing existing material features. Disjoint composed perimeter chamfers are supported within their station/corridor limits.
- STEP import normalizes recognized declared length units to millimetres, and the parsed document retains the conversion factor. Public engineering measurements use millimetres; imported topology does not preserve the original unit entity as an editable semantic object.
- Standard Library material resolution is qualified for Firmament FEA and authored Sheet Metal. Ordinary prismatic CAD STEP export does not yet persist a general solid-material designation; do not infer one from the geometry artifact.
- Cadmata may emit one Three.js `Clock` deprecation warning in the browser developer console. It does not affect loading, navigation, selection, PMI interaction, or model switching.
- Canonical STEP byte hashes can differ across operating systems because recovered trim coordinates have tiny floating-point differences. Compare engineering geometry rather than using byte hashes alone for cross-platform CI comparisons; the qualified platforms retain strict separate corpus snapshots.
- Normal validation includes domain-specific engineering preflight. Swept and spline-heavy models can take seconds; parse-only validation is explicitly limited. Expansion source maps are incomplete, so some diagnostics disclose enclosing locations rather than an exact authored token.
