# Development documentation

This index marks the non-public documentation boundary. The authoritative user-facing Preview 3 contract is [`docs/public`](../public/README.md).

- `docs/release/` and `docs/milestones/`: hardening and historical milestone reports
- `docs/architecture/`, `docs/implementation/`, and root architecture notes: internal design and migration records
- `docs/**/artifacts/`: experimental/qualification evidence and generated artifacts
- `docs/research/`, `docs/continuum/experiments/`, and similarly named reports: research or experimental work
- feature-specific legacy directories: implementation archaeology that may predate current syntax

These documents explain why the system evolved and preserve evidence. They do not override public docs or the current executable. Maintainer build/test policy remains in [`docs/build-test-policy-net10-and-legacy-v1.md`](../build-test-policy-net10-and-legacy-v1.md).
