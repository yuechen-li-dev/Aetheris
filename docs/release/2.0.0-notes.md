# Aetheris 2.0.0

Aetheris compiles Firmament source into engineering artifacts. Source can be
reviewed in Git and built in CI; the same compiler supplies validation and
structured diagnostics to the CLI, SDK and CAD application.

## Installation and artifacts

- Install the managed tool with `dotnet tool install --global Aetheris.CLI --version 2.0.0` using .NET 10.
- Windows x64 has a self-contained ZIP including browser-first Cadmata and the NativeAOT Forge Host. `Cadmata.exe` opens your existing browser; the optional `Cadmata.Desktop.exe` uses shared Evergreen WebView2. The normal ZIP contains no private Chromium/WebView2 runtime and installs none automatically.
- The portable CLI package is qualified on Windows x64 and Linux x64. Other platforms are not claimed as qualified by this release.
- The public library package set includes its complete Aetheris project dependency closure. Copeland's managed VTS/WGSL compiler family is pinned to public version 0.1.0; no sibling checkout or private feed is required.
- Verify artifacts against SHA256SUMS.txt and RELEASE-INVENTORY.md. Forge protocol and VS Code extension versions are independent of the product version.

The core CLI carries no third-party OS-native geometry, SQLite, PDFium, Skia or
Rhino runtime. PDF drawing generation remains managed. Drawing Notes use pinned
PDF.js browser assets. SQLite material storage and 3DM interoperability are
optional adapters; the latter has its own command-line tool.

## CAD inspection and interchange

Cadmata starts with a blank workspace, supports exact standard views including
top and bottom, and keeps generated product filenames for STEP downloads.
Viewport and form controls align across desktop and narrow layouts; Measure
uses the application's engineering palette. Nonfatal import diagnostics are
summarized in the UI, with full messages available in downloadable logs.

Straight/Bend WireForm STEP exports preserve analytic cylinders, toroidal
bends and circular edges with corrected boundary winding. Import derives exact
linear UV trims for their cylinder/torus rings and seams instead of fitting
redundant B-splines. Existing source-supplied trim curves remain preserved.

## Frontend integrity

Validation and build share command-level domain selection. Native V2 `model`
is a case alias for `Model`; the existing serialized and `solid`-grammar legacy
boundaries remain explicit. Unknown fields reject at their owning readers,
including assembly occurrences and Semantic publications, WireForm operations,
SectionChain construction guides, semantic requirements and projected PMI.
Wrong-dimensional profile coordinates reject instead of silently becoming
millimetres. Diagnostics retain codes and messages through the CLI JSON contract.

This release preserves the existing bounded geometry capabilities. Unsupported
operations remain errors; it does not promise arbitrary BRep booleans, general
edge blending or unrestricted STEP surgery. Assembly exports include assembly
PMI explicitly authored at assembly scope; part PMI is not implicitly promoted.
See [supported features](../public/reference/supported-features.md) and
[known issues](../public/reference/known-issues.md).

## Experimental APIs

Cloth3D, Humanoid and experimental module APIs are included at the product
version so the published graph restores completely. Their behavior remains
experimental, as documented under docs/public/experimental; a package version
is not a claim that those workflows are production-qualified. Fields and
PlasticShell retain their documented bounded capability contracts.

## Validation cost and limits

Normal validation performs the preflight required by its domain. Swept and
B-spline-heavy models can take seconds; orientation and interchange safety
checks have not been removed to improve timing. Parse-only validation is
explicitly limited and does not prove engineering build success. Original-source
mapping after expansion is still incomplete; diagnostics disclose enclosing
locations when exact provenance is unavailable.
