# Samples

Samples show how an external consumer integrates Aetheris. This includes package-consuming applications and Forge Host clients in other languages.

Use `samples/` for “how a consumer calls Aetheris.” Use [`demos/`](../demos/README.md) for a runnable narrative that demonstrates an Aetheris capability. A new Python Forge Host integration example belongs here.

- [`web-sdk-pocket-view/`](web-sdk-pocket-view/) is a framework-free browser frontend that consumes the public `@aetheris/cad` package, compiles the canonical bracket, projects its mesh to canvas, lists semantic nodes, and exports STEP.
