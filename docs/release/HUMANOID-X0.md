## Canonical authority

`Aetheris.Humanoid` is a domain module beside the existing engineering domains. `ImportedHumanoid` retains external topology, source pose, and provenance. `CanonicalHumanoid` requires the stricter Aetheris identity and validation laws. No Firmament syntax is frozen.

The canonical frame is millimetres, right-handed, +X anatomical right, +Y forward, +Z up. The origin is the mid-sagittal pelvis projection on the common sole plane. The authored neutral is normalized to exactly 1750 mm; this is an engineering normalization, not a population mean.

The canonical artifact is generated by repository code from explicit anatomical SDF primitives on a fixed 24 mm lattice, split into six deterministic tetrahedra per cell and polygonized at the zero isovalue. Faces below 0.0001 mm2 are deterministically rejected. Antonia coordinates and connectivity do not participate in generation.

The surface has stable vertex and face IDs, binding triangles, explicit region symmetry, vertex symmetry involution, component declarations, and semantic material regions. The outer skin, left eye, and right eye are separate components. The mouth seam is surface-only; a mouth interior, teeth, and tongue are deferred. Connectivity is triangle-based and generated from a tetrahedral lattice. It is not quad-dominant and does not yet provide artist-authored deformation loops. Hands have separated authored finger primitives and semantic chains, but the lattice resolution limits finger and facial detail.

The full JSON/OBJ artifacts and before-fit renders are generated under `artifacts/local/humanoid-x0/`. The compact tracked fixture is `fixtures/Canonical/Humanoid/adult-standard-v1.fixture.json`.

## Skeleton, bind, and pose

The canonical skeleton has 55 semantic joints: root/pelvis/spine/chest/neck/head; bilateral clavicle, shoulder, elbow, wrist, hip, knee, ankle, and toe base; three-joint thumb chains; three-joint index/middle/ring/little chains. Eye and jaw kinds are declared optional but are not required by the X0 skeleton. External rig names are never canonical authority.

Rest and bind are the shaped instance's canonical A-pose. Local transforms map child-local coordinates into the parent. Runtime math uses System.Numerics row-vector matrices: `pWorld = pModel * InverseBind * GlobalPose`. Bind reconstruction is validated to 0.001 mm. Procedural region-based weights are finite, nonnegative, bounded, and normalized per vertex. X0 uses linear blend skinning.

The bounded sweep evaluates shoulder 35°/70°, elbow 45°/90°, hip 35°/70°, and knee 45°/90°. All eight cases are finite, preserve face identity, have zero collapsed triangles, and move surface-bound attachment points with their semantic follow joints. Surface-area ratios range from 1.003 to 1.119 and absolute-volume ratios from 0.985 to 1.006. The current orientation-reversal proxy reports 48–203 affected triangles depending on pose, so the sweep is **not accepted as stable deformation**. This isolates procedural joint weights and coarse joint-region topology as a remaining foundation blocker; no cinematic-quality claim is made.

## Landmarks, measurements, and attachments

Landmark types remain separate: `SurfaceLandmark`, `JointLandmark`, `MeasurementLandmark`, and `AttachmentLandmark`. Surface landmarks bind by topology ID, stable face ID, binding triangle, and barycentric coordinates. X0 contains 33 surface and 55 joint landmarks. Placement protocol, confidence, symmetry partner, provenance, and review status are explicit. Authored surface points are marked unreviewed pending human anatomical review.

Nineteen attachment sites cover head, face, chest, upper back, waist, bilateral upper arm, wrist, hand, thigh, shin, ankle, and foot. ## Intended API use

```csharp
var humanoid = CanonicalAdultTemplate.Create();
var measurements = HumanoidMeasurements.Evaluate(humanoid);
var pose = new HumanoidPoseState(
    "elbow-45",
    [new(HumanoidJointKind.LeftElbow,
        Quaternion.CreateFromAxisAngle(Vector3.UnitY, MathF.PI / 4))],
    HumanoidTransform.Identity);
var wrist = HumanoidPosing.EvaluateAttachment(humanoid, "site:Wrist.Left", pose);

var tall = HumanoidMorphing.Apply(humanoid, new Dictionary<HumanoidMorphId,double>
{
    [HumanoidMorphId.Height] = 1800,
    [HumanoidMorphId.LegLength] = 35
});
```

The CLI artifact path supports the same operations through `generate`, `inspect`, `morph`, `pose`, and `sweep` commands. The fit handoff requires only this guide, the sidecar, template artifact/ID, frozen config, Blender, and the hash-pinned blend; it does not require CharMorph internals.

```powershell
dotnet run --project tools/Aetheris.Humanoid.X0 -- generate --out-dir artifacts/local/humanoid-x0
dotnet run --project tools/Aetheris.Humanoid.X0 -- inspect --input artifacts/local/humanoid-x0/canonical-adult-standard-v1.json
dotnet run --project tools/Aetheris.Humanoid.X0 -- morph --input artifacts/local/humanoid-x0/canonical-adult-standard-v1.json --output artifacts/local/humanoid-x0/adult-1800.json --height 1800 --leg-length 35
dotnet run --project tools/Aetheris.Humanoid.X0 -- pose --input artifacts/local/humanoid-x0/canonical-adult-standard-v1.json --output artifacts/local/humanoid-x0/elbow-45.obj --left-elbow-deg 45
dotnet run --project tools/Aetheris.Humanoid.X0 -- sweep --input artifacts/local/humanoid-x0/canonical-adult-standard-v1.json --output artifacts/local/humanoid-x0/pose-sweep-evidence.json
```

CLI joint-degree controls use the same right-handed local rotation axes as the C# API: shoulder/elbow use +Y and hip/knee use +X. `left-elbow-deg 45` therefore matches the C# example. Attachment JSON orders its orthonormal basis as `tangent`, `normal`, `binormal`, followed by its posed `position`. A height morph updates both the evaluated `Height` protocol and `Frame.NormalizedHeightMm`; the unchanged 1750 mm value identifies only the neutral authored template.

## Boundaries

This is one adult reference and one authored neutral. Diversity and cross-body qualification are deferred. There is no mean-body, PCA, broad-population, medical, child, or elderly claim. There is no second admitted reference. Reom remains excluded.

The face is neutral and coarse, without expression basis, FACS, lip sync, or a qualified mouth interior. Shoulder and hip skinning fail the current pose-orientation screen. Hands and feet are semantic but low-detail. There is no qualified self-intersection detector, garment or hair system, gait or grasp solver, ML model, VRoid parser, runtime dependency on CharMorph, or manufacturing-BRep representation of skin.

The completed substrate removes the need to rediscover IDs, frame, region vocabulary, skeleton, binding convention, typed landmarks, measurements, attachments, morph boundaries, diagnostics, and provenance. Acceptance now depends on improving registration correspondence/deformation and joint-region skinning, not on inventing another humanoid architecture.
