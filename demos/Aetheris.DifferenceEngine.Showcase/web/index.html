THE IDEA BEHIND THE MACHINE

Arithmetic by addition.

A Difference Engine generates polynomial sequences through repeated addition. Here, each turn adds the first difference to the result, then the second difference to the first.

For squares: 0, 1, 4, 9, 16… The first differences are 1, 3, 5, 7… The second difference stays at 2.

Charles Babbage conceived the Difference Engine. Ada Lovelace’s 1843 notes explored his later Analytical Engine and its wider possibilities.

This is a Babbage-inspired design, not a historical replica. The CAD is real; the animation illustrates the arithmetic.
