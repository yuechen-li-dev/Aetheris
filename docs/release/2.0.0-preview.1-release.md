## Distribution decision

`Aetheris.CLI` is the only Preview 1 NuGet package. It is a .NET 10 global
tool for validation, STEP build, inspection, analysis, and verification.
Cadmata is intentionally internal to the Windows bundle: the complete
download-and-run viewer route is the GitHub ZIP, and the NuGet tool documents
that `view` requires that bundle. Kernel, Firmament, Forge, server, and
Cadmata assemblies are implementation assemblies for this preview rather than
an established supported SDK surface, so they are `InternalOnly`/`Defer`.

## Package metadata and trusted publishing

`Aetheris.CLI` version `2.0.0-preview.1` has a tool command of `aetheris`, an
AGPL-3.0-only license expression, repository and project URLs, concise tags,

environment `production`, package owner `yuechen-li`). The publish job had
only `contents: write` and `id-token: write` permissions and used the
`production` environment.

## Build, test, and smoke evidence

The exact-artifact workflow restored, built, tested, packaged, and smoke-tested
once before promoting its workflow artifact. It completed successfully:

- Core tests: 994 passed
- Firmament tests: 1,028 passed
- CLI tests: 348 passed
- Server tests: 45 passed
- Frontend tests: 58 passed; Vite production build passed

Local package smoke installed `Aetheris.CLI` from a temporary local feed and
ran `aetheris --version`, `--help`, `validate`, `build`, `inspect`, and
`verify`. The .nupkg contains the expected tool payload, tool settings,
metadata, and README; it contains managed PDB symbol files but no source,
test, `.env`, or credential files.

The workflow clean ZIP smoke extracted the exact uploaded artifact outside the
repository and ran `--version`, `--help`, `validate`, `build`, `inspect`, and
`verify`. The public GitHub download was independently downloaded again,
verified against `SHA256SUMS.txt`, extracted fresh, and passed `--version`,
`--help`, `validate`, `build`, `inspect`, `verify`, and STEP `analyze`.
Cadmata's `wwwroot/index.html` and 15 production assets were present;
`aetheris view` launched Cadmata package-relatively for both Firmament and
STEP input.

The publicly downloaded bundle also built and verified representative
counterbore, Concept Path + Extrude, Compose L-bracket with counterbore/PMI,
supported chamfer, bounded fillet, projected PMI, and outside-Compose Modify
regression fixtures. The outside-Compose Modify route built its requested
geometry rather than silently materializing a different body.

NuGet.org was queried directly after publication. Its flat-container index
listed `2.0.0-preview.1`; a fresh `dotnet tool install --tool-path ...
--source https://api.nuget.org/v3/index.json --no-http-cache Aetheris.CLI
--version 2.0.0-preview.1` succeeded and the installed tool passed
`--version`, `--help`, `validate`, and `build`. The first ordinary client
query observed normal HTTP cache propagation and was retried without cache;
no artifact was republished or replaced.

## Release notes and documentation

Release notes present the Preview 1 exact-code-first CAD baseline, Firmament
V2, AP242 output, bounded geometry features, Cadmata, and the VSIX. They also
state the frozen limitations. Public documentation now describes both the
Windows bundle and NuGet routes and explicitly says that NuGet does not bundle
Cadmata. The documentation deployment completed successfully at
<https://github.com/yuechen-li-dev/yuechen-li-dev.github.io/actions/runs/31250232028>.

## Known Preview 1 limitations

- Mixed whole-loop Fillet remains Experimental.
- Concept Path-derived Profile is not accepted by Compose.
- Foreign STEP recognition/replacement is deliberately bounded.
- Parasolid chamfer interoperability has a known limitation.
- Tessellated BRep volume is non-authoritative; CIR/FRep authoritative volume
  work is deferred.

## Preview 2 handoff

Preview 1 is closed. The intentionally deferred next work is recorded in
[`docs/roadmap/preview2-start.md`](../roadmap/preview2-start.md), including
CIR/FRep volume authority, whole-loop Fillet lowering/promotion, Concept Path
to Compose, diagnostic source spans, Cadmata MachinaLayout.js and TSPack work,
broader foreign STEP coverage, and the Parasolid investigation.
