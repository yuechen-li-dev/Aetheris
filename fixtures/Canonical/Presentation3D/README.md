# PRESENTATION-3D-X0 fixtures

`interactive-3d-demo.json` is the bounded two-slide authoring input for the C#
presentation compiler. It refers to generated local GLBs and fallback PNGs.

`office-model3d-oracle.xml` is a compact regression extract from
`powerpoint-reference.pptx`, authored by the user in desktop PowerPoint
16.0.20430.20118 on 2026-10-02 using Insert → 3D Models → This Device.
The local oracle contains ATLAS and guitar on slide 2. The extract retains the
first model's AlternateContent, model/camera/transform/lighting/raster structure
and fallback. Creation/modification identifiers were removed. Embedded binaries
and the complete original package remain under ignored
`artifacts/local/presentation-3d-x0/`.

ATLAS is an independent Aetheris demo robot. Aetheris is not affiliated with,
endorsed by, or associated with Boston Dynamics. The shared name is coincidental.
