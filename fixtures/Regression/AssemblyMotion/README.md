not yet admitted. Current parsing rejects `Interface<SliderCrank>` with
`assembly-interface-family-invalid`. This is an explicit missing capability,
not an accepted geometry regression or a source spelling to work around.

`fixtures/Canonical/AssemblyInterfaces/articulated-*.firmament` and
`derived-datum-frames.firmament`.
